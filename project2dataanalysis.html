Data Analysis Reflection

In my second project this year, I learned how to use Google Sheets to analyze data and built a dashboard that contained data on NBA player stats throughout the 24/25 season. This project helped me discover how to show and analyse data properly, as well as using these features to extract meaningful insights. I learned how to create charts and graphs via Google Sheets to visualize the data, also helping me to better understand the trends and patterns in the information. I also learnt how to create funnels to make the dashboard interactive and even create different types of graphs depicting set values from the spreadsheet. However, during this project, I also experienced several setbacks, some of which was due to the large scale of the data causing my laptop to frequently crash and cause issues. Despite this, I learned how important planning, patience, and problem-solving are. I also improved my ability to use design features, structure information clearly, and make choices that helped the overall presentation. Overall, this project was a great opportunity for me to develop my data analysis skills and gain a deeper understanding of how to work with data effectively.
